Notes & Usage
  1. Effective ranges of input parameters are mentioned inside the input fields.
  2. For known dataset: upload an Excel/CSV file with input and output columns; columns must follow the order in note 3, with the measured compressive strength as the rightmost column (col 13). For multiple datasets: upload an Excel file with only the 12 input columns (same order).
  3. Column order: W/B, Cement, Water, VSA, Silica Fume, Metakaolin, Nano-Silica, Fine Aggregate, Coarse Aggregate, Superplasticizer, MAM, Age (+ CS for known data).
